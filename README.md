# cymdeithion

[![CI](https://github.com/AncientSwordRage/cymdeithion/actions/workflows/ci.yml/badge.svg)](https://github.com/AncientSwordRage/cymdeithion/actions/workflows/ci.yml)

*Cymdeithion* is the Welsh word for *companions* or *fellow-travellers*. This repository aims to assist in making calculations of a known fixed orbit. As the motion is derived solely from Keplers laws (TODO, add link), and the systems motion doesn't evolve, the program doesn't claim to be an orbital simulation. However sufficient calculations are provided that the amount of gravitational perturbations can be calculated.
